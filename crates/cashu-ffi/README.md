# cashu-ffi

UniFFI bindings for the [`cashu`](../cashu) crate's protocol and crypto
primitives: blinding, unblinding, NUT-13 deterministic derivation and NUT-11
P2PK locks.

This is deliberately smaller than [`cdk-ffi`](../cdk-ffi). It carries no wallet,
no database and no async runtime, because it exists to give a JavaScript,
Swift or Kotlin wallet the parts it cannot compute quickly on its own.

## Surface

Free functions cover hashing, blinding, unblinding, DLEQ verification, keyset
ids and amount splitting. Batch functions take the exact denominations to
produce rather than an amount to split: splitting is cheap and every wallet has
its own policy for it, while the caller's ordering decides which NUT-13 counter
each output gets.

`DeterministicOutputFactory` holds a 64 byte BIP39 seed so a wallet copies it
across the FFI once instead of on every derivation. The seed is redacted from
`Debug` and zeroed on drop.

Every entry point that takes a seed or a secret wraps the buffer UniFFI
allocated for the argument in `zeroize::Zeroizing` before doing anything else,
so it is wiped when the call returns, whether it succeeded or failed. Copies
the compiler makes along the way are not tracked, and the copy on the foreign
side (the JavaScript `Uint8Array`, the Swift `Data`, the Kotlin `ByteArray`) is
the caller's to clear. Prefer the factory over the seed-taking free functions
so the seed crosses once.

## Bindings

The React Native target is generated by
[`uniffi-bindgen-react-native`](https://github.com/jhugman/uniffi-bindgen-react-native);
see [`bindings/react-native`](../../bindings/react-native). The same crate
works with the stock UniFFI generators for Swift, Kotlin and Python.

This crate pins `uniffi` to `=0.31.2` rather than taking the workspace's
`0.30`. `uniffi-bindgen-react-native` needs 0.31, and the workspace cannot move
because `bindings/dart/rust` depends on a `uniffi-dart` build that only exists
for 0.30. The two versions coexist safely: `cdk_ffi` and `cashu_ffi` are
separate libraries that are never linked together, and UniFFI prefixes every
exported symbol with the crate name.

## Tests

```sh
cargo test -p cashu-ffi
```

The tests check the exported functions against the NUT-00 `hash_to_curve` and
NUT-13 derivation vectors, so a change here that would move a wallet's secrets
fails the build.
